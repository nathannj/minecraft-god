# Changelog

## 0.1.0 — unreleased

First public-repository candidate.

- Multiplayer minimap/world map, live player markers, waypoint sharing and an isolated Fabric client profile/Modrinth pack.
- Simple Voice Chat proximity audio and local speech recognition with speaker identity, spatial context, recipient-aware god routing and per-player opt-out.

- Persistent per-player gods, private prayers, deterministic objective watches, and a shared pantheon with permissioned interventions.
- Scoped MCP commands, live world observations, protected regions, durable event delivery, and recoverable narrative state.
- Authenticated event polling/delivery, validated identities, corrected spatial event fields, and bounded structure imports.
- Serialized private camera captures, configurable session/turn limits, and reported token metrics.
- Portable Python packaging, a network-free demo, installation diagnostics, backup/restore tools, pinned setup downloads, and reproducible plugin archives.
- Python regression tests, Java HTTP/outbox tests, a Java/Python event contract, clean-wheel verification, CI, and a draft-release workflow.

This version is not a claim of production readiness or unlimited multiplayer capacity. See [release evidence](docs/release-readiness.md) and the remaining human playtest checklist.
